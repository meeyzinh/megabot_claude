🏠 Hướng dẫn kết nối Home Assistant với Megabot AI

Hướng dẫn này giúp bạn cài integration MCP Server for Xiaozhi vào Home Assistant, sau đó kết nối Home Assistant với thiết bị Megabot AI để điều khiển nhà thông minh bằng giọng nói.

📌 Bạn cần chuẩn bị trước

  • Home Assistant đã cài và hoạt động bình thường.
  • Đã cài HACS trong Home Assistant.
  • Đã có tài khoản Megabot AI hoạt động.
  • Đã có token WSS endpoint của thiết bị Megabot.

1. Cài HACS nếu chưa có

Nếu Home Assistant của bạn chưa có HACS, hãy cài HACS trước.

Xem hướng dẫn HACS: https://www.hacs.xyz/docs/use/

2. Cài MCP Server for Xiaozhi qua HACS

  1. Mở Home Assistant.
  2. Vào HACS.
  3. Vào mục Integrations.
  4. Tìm xiaozhi hoặc ha-mcp-for-xiaozhi.
  5. Chọn MCP Server for Xiaozhi.
  6. Bấm tải/cài đặt.
  7. Sau khi cài xong, khởi động lại Home Assistant.
Nếu không tìm thấy trong HACS, hãy thêm custom repository: 
https://github.com/c1pher-cn/ha-mcp-for-xiaozhi
Category chọn Integration, sau đó tìm lại xiaozhi.

3. Thêm Thiết bị Megabot vào Home Assistant

  1. Trong Home Assitant.
  2. VàoCài đặt.
  3. Chọn Thiết bị & Dịch vụ.
  4. Chọn MCP Server for Xiaozhi.
  5. BấmThêm dịch vụ.

4. Nhập token WSS endpoint Megabot

Khi Home Assistant yêu cầu nhập MCP endpoint, dán token WSS endpoint bạn nhận được từ admin Megabot.

Sau đó chọn MCP / function bạn muốn cho Xiaozhi sử dụng. Mục Assist là function có sẵn của Home Assistant. Các mục khác là MCP server khác nếu bạn đã cấu hình thêm trong Home Assistant.

Không chia sẻ WSS token cho người khác. Token này giống như khóa kết nối giữa Home Assistant và thiết bị Megabot của bạn.

5. Kiểm tra trạng thái kết nối

  1. Sau khi submit cấu hình trong Home Assistant, chờ khoảng 1 phút và thử nói với Megabot: "Kiểm tra các thiết bị trong nhà" => Nếu Megabot cập nhật và đọc được các thiết bị trong Home Assistant là đã kết nối thành công
Có thể sử dụng các câu trò chuyện tự nhiên để điều khiển thiết bị trong HASS mà không cần câu lệnh cụ thể chính xác.

6. Cách yêu cầu WSS endpoint từ admin Megabot

  1. Đăng nhập trang quản lý Megabot AI.
  2. Chọn menu 🔗 Yêu cầu kết nối Home Assistant.
  3. Nhập email của bạn.
  4. Bấm gửi yêu cầu.
  5. Admin sẽ gửi token WSS endpoint qua email bạn cung cấp.

⚠️ Các lỗi thường gặp

Không tìm thấy integration sau khi cài

Hãy restart Home Assistant, sau đó vào lại Settings → Devices & Services → Add Integration.

Kết nối không online

  • Kiểm tra WSS endpoint có bị copy thiếu không.
  • Kiểm tra token có đúng không.
  • Chờ 1 phút rồi refresh lại trạng thái ở trang Xiaozhi.
  • Kiểm tra Home Assistant có truy cập Internet bình thường không.

AI không điều khiển đúng thiết bị

  • Kiểm tra đã chọn đúng MCP / Assist trong cấu hình integration.
  • Đặt tên thiết bị trong Home Assistant rõ ràng, dễ hiểu.
  • Thử nói rõ tên phòng và tên thiết bị.
